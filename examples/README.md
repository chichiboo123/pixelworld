# PIXEL WORLD · 갤러리 예시작품

다양한 규모의 캔버스에 **자연풍경 · 우주 · 동물 · 캐릭터** 예시 작품을 만들어
도안 갤러리에 올릴 수 있도록 준비한 모음입니다. 모든 작품은
[`generate.py`](generate.py) 가 코드로 그려 내며, 언제든 다시 만들거나 수정할 수 있습니다.

## 폴더 구성

```
examples/
├── generate.py          # 작품을 그려 내는 파이썬 스크립트(여기서 모두 생성됨)
├── upload.html          # 브라우저에서 한 번에 갤러리로 올리는 업로더
├── gallery_seed.json    # 업로드용 작품 데이터(17개 배열)
├── contact_sheet.png    # 전체 미리보기 한 장
├── patterns/            # 작품별 도안 파일(.json) — 앱 "도안 불러오기"로 열 수 있음
└── previews/            # 작품별 미리보기 이미지(.png)
```

## 갤러리에 올리는 방법

### 방법 A — 한 번에 올리기 (권장)

1. **인터넷이 되는 컴퓨터**에서 [`upload.html`](upload.html) 파일을 더블클릭해 브라우저로 엽니다.
2. 17개 작품 미리보기가 보입니다. 빼고 싶은 작품이 있으면 카드의 체크를 풉니다.
3. **〔전체 업로드 시작〕** 버튼을 누르면 차례대로 갤러리에 올라갑니다.
   각 카드에 `✓ 완료` 표시가 뜨면 성공입니다.

> ⚠️ **한 번만 실행하세요.** 누를 때마다 같은 작품이 새로 추가됩니다(중복 방지 기능 없음).
> 갤러리는 삭제가 어려우므로, 올리기 전에 미리보기로 확인하세요.

### 방법 B — 한 작품씩 앱에서 올리기

1. PIXEL WORLD 앱을 엽니다.
2. 더보기 메뉴 → **도안 불러오기**로 `patterns/` 폴더의 `.json` 파일을 엽니다.
3. **갤러리에 올리기**로 작품명·작가를 확인하고 업로드합니다.

## 다시 만들거나 수정하기

```bash
cd examples
pip install pillow        # 미리보기 PNG 생성용
python3 generate.py       # patterns/ · previews/ · upload.html · gallery_seed.json 재생성
```

- 새 작품을 추가하려면 `generate.py` 안에 `art_...()` 함수를 만들고 `main()` 의 `builders` 목록에 넣으면 됩니다.
- 작가 이름은 `AUTHOR` 변수(기본값 `"치수쌤 갤러리"`)에서 한 번에 바꿀 수 있습니다.
- 캔버스 크기는 `SIZE_PRESETS`(앱 `app.js` 와 동일) 안의 값만 사용해야 갤러리 필터가 올바르게 동작합니다.

## 도안 데이터 형식 (참고)

업로드 payload는 앱이 서버로 보내는 것과 동일합니다.

```jsonc
{
  "title":  "작품명",
  "author": "작가",
  "ratio":  "landscape | square | portrait",
  "sizeKey":"small | medium | large | xlarge",
  "cols": 24, "rows": 24,
  "legend": [ { "num": 1, "color": "#ff5fa2" }, ... ],
  "cells":  [ 0, 1, 2, ... ]   // 길이 = cols*rows, 0=빈 칸, 그 외는 legend 번호
}
```

`cells` 는 위→아래, 왼→오른 순서(row-major)입니다.
