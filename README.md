# PIXEL WORLD (픽셀월드)

> 초등학생을 위한 브라우저 픽셀 아트 창작 도구

**PIXEL WORLD**는 어린이가 직관적으로 픽셀 아트를 그리고, 저장하고, 친구와 공유할 수 있도록 만든 웹 기반 드로잉 앱입니다. 별도의 설치 없이 브라우저만 있으면 바로 시작할 수 있고, 작업 중인 그림은 자동으로 저장되어 새로고침이나 재접속 후에도 이어 그릴 수 있어요.

---

## 주요 기능

### 단계별 시작 화면
1. **캔버스 모양 선택** — 가로 / 정사각형 / 세로
2. **그림 크기 선택** — 소 · 중 · 대 (선택한 모양에 따라 픽셀 해상도가 달라져요)
3. **메인 작업 화면** 진입

### 그리기
- **원-탭 토글 방식**: 빈 칸을 누르면 선택한 색이 칠해지고, 같은 색으로 칠해진 칸을 다시 누르면 지워집니다. 별도의 지우개 도구가 없어 더 직관적입니다.
- **드래그 그리기**: 누른 채로 드래그하면 연속해서 칠하거나 지울 수 있어요.
- **붓 크기 선택**: 1칸 · 4칸(2×2) · 9칸(3×3) 토글.
- **20색 기본 팔레트** + **사용자 지정 색상** 피커.

### 화면 도구
- **홈으로 / 이전 단계**: 작업 화면에서도 언제든 모드·크기 선택 화면으로 이동.
- **되돌리기(Undo) / 다시 실행(Redo)**: 최대 50단계 기록. 키보드 단축키 `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`도 지원.
- **전체 지우기**: 확인 모달로 실수 방지. Undo로 복구 가능.
- **중앙 가이드라인**: X축·Y축 중앙에 점선 가이드를 표시/숨기기 토글. 상태는 자동 저장.
- **그림 참고하기**: 우측 패널에 로컬 이미지를 띄워 캔버스를 가리지 않고 참고.

### 저장 · 내보내기
- **LocalStorage 자동 저장**: 그리는 동안 자동으로 백업되어 새로고침해도 사라지지 않아요.
- **JPG 다운로드 / 이미지 클립보드 복사 / 링크 공유** — 내보내기 3버튼 (아이콘 위주 한 줄 UI)
- **디스켓 메뉴**: 작업 상태를 JSON으로 저장하거나 다시 불러오기.
- **링크 공유**: 캔버스를 팔레트 + 런렝스 압축으로 인코딩하여 URL 해시(`#art=...`)로 만들고, 다른 기기에서 그 링크를 열면 동일한 그림이 복원됩니다.

### 반응형 · 뷰포트 최적화
- 에디터 화면은 `100dvh` 기준으로 viewport에 고정되어 스크롤 없이 캔버스가 꽉 채워집니다.
- `ResizeObserver`로 사이드바·참고 패널 열기/닫기, 윈도우 리사이즈 시 캔버스 크기를 자동 재계산합니다.
- 모바일에서는 캔버스가 최상단으로, 도구 패널이 아래로 재배치됩니다.
- Footer는 뷰포트 하단에 항상 고정됩니다.

## 사용 방법

별도 빌드 과정이 필요 없는 정적 웹앱입니다.

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저로 직접 열거나, 정적 서버로 서빙합니다.
   ```bash
   # 예: Python 내장 서버
   python3 -m http.server 8000
   ```
3. 브라우저에서 `http://localhost:8000` 접속.
