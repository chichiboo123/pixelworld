1. 처리 주체와 문서 상태

PIXEL WORLD는 브라우저에서 그림을 그리고 도안을 공유하는 서비스입니다. 운영자 및 개인정보 담당자: [운영자 확인 필요]. 개인정보 문의·권리행사 연락처: [운영자 확인 필요]. 이 문서는 2026-10-16 코드 분석에 따른 검토용 초안입니다. 시행일: [운영자 확인 필요]. 현재 유효한 처리방침으로 공표된 문서가 아닙니다.

2. 내 기기에 저장하는 그림과 설정

편집한 픽셀·도안, 모양·크기, 색·붓, 가이드와 현재 화면은 같은 사이트의 브라우저 LocalStorage(pixelworld:v1)에 저장되어 작업을 복원합니다. 언어(pixelworld:lang), 지우기 도움말 표시(pixelworld:eraseHintShown), 갤러리 보기 크기(pixelworld:galleryDensity)도 저장합니다. 이 값에는 코드상 자동 만료가 없습니다. 같은 기기·브라우저 프로필을 쓰는 사람이 볼 수 있습니다. 그림의 자동 저장 자체가 갤러리 업로드는 아닙니다. 브라우저에서 이 사이트의 저장 데이터 삭제를 선택하면 로컬 저장을 지울 수 있습니다. 전체 지우기 버튼은 모든 설정과 저장 항목을 지우는 기능이 아닙니다.

3. 참고 이미지·파일·클립보드·공유 링크

참고 이미지는 선택한 파일을 브라우저에서 읽어 표시하고, 코드상 서버에 업로드하거나 자동 저장하지 않습니다. 이미지 지우기 또는 페이지 종료로 화면의 참고 이미지를 없앨 수 있으며 원본 파일은 그대로 남습니다. 그림·도안 JSON을 불러오면 브라우저에서 읽고 작업 데이터로 로컬 저장할 수 있습니다. 다운로드한 JPG/JSON과 클립보드 이미지는 사용자의 기기·운영체제에서 관리합니다. 링크 공유는 그림을 압축해 URL의 #art= 뒤에 넣습니다. 압축은 암호화가 아닙니다. 링크를 받은 누구나 그림을 복원할 수 있고 접근 제한·링크 만료·원격 회수 기능은 없습니다. URL fragment는 일반 HTTP 요청에 포함되지 않지만 링크를 전달한 서비스·동기화·기록에 남을 수 있습니다. 링크를 열면 그림은 받는 브라우저에도 저장될 수 있습니다.

4. 공개 갤러리에서 처리하는 정보

갤러리 업로드 시 작품명, 작가 별명, 선택한 국가 코드·국가명, 도안의 크기·모양·색상 범례·칸 데이터를 Google Apps Script로 보내 Google Sheets에 저장하는 구조입니다. 서버는 게시물 ID, 생성일시 및 도안별 조회수도 만듭니다. 이 정보는 공개 목록 API와 갤러리를 통해 누구나 읽을 수 있으며 회원에게만 제한되지 않습니다. 갤러리 도안을 열면 도안 ID가 Google로 전송되어 조회수가 올라갑니다. 국가 정보는 직접 선택하는 표시 항목이며 GPS 위치를 수집하는 기능은 없습니다. 공개 갤러리의 목적은 도안 전시와 색칠 자료 공유입니다. 개인정보에 해당하는 항목의 수집·공개 법적 근거와 별도 동의 필요성: [운영자 확인 필요]. 공개 안내 확인 체크만으로 적법한 개인정보 동의가 확보되었다고 보지 않습니다. 실명·학교·학년·반·번호·연락처 및 타인의 개인정보를 작품과 글에 넣지 마세요.

5. 보유기간·삭제·파기

브라우저 작업 데이터에는 자동 만료가 없고 새 작업으로 덮어쓰거나 사이트 데이터를 삭제할 때까지 남을 수 있습니다. 서버 갤러리에도 현재 자동 만료·기간별 파기 코드는 없습니다. 목적에 맞는 게시물 보유기간·삭제 기준과 파기 운영 절차: [운영자 확인 필요]. 이용자가 서버 게시물을 직접 수정·삭제하는 기능은 없고 관리자만 해당 행의 수정·삭제를 할 수 있습니다. Google Sheets의 버전기록·휴지통·백업 보존 및 최종 파기 기간: [운영자 확인 필요]. 서버 행 삭제만으로 모든 사본이 즉시 영구삭제된다고 보장할 수 없습니다. 다른 사람이 내려받거나 전달한 파일·링크 사본은 별도로 남을 수 있습니다.

6. 외부 서비스·제3자 제공·위탁·국외 이전

웹페이지는 GitHub Pages에 배포하도록 구성되어 있고 외부 글꼴·아이콘을 Google Fonts와 jsDelivr에 요청합니다. 갤러리를 열고 이용하면 Google Apps Script에 요청합니다. 각 접속 대상에 IP와 HTTP 요청 헤더 등 접속 정보가 전달될 수 있습니다. 앱에서 별도 접속 로그를 저장하는 코드는 발견되지 않았지만 플랫폼 로그 수집·보유가 없다는 뜻은 아닙니다. GitHub·Google·CDN의 계약 주체, 처리 역할, 실제 로그·쿠키·보유기간과 운영자 접근 범위: [운영자 확인 필요]. 처리위탁인지 제3자 제공인지, 국외 저장·조회가 있는지 각각 계약과 설정에 따라 확인해야 합니다. 국외 이전이 있으면 받는 자와 연락처·국가·항목·이전 시기/방법·목적·보유기간·적법한 근거·거부 방법과 영향을 공개 전에 채워야 합니다: [운영자 확인 필요]. 실제 국가를 확인하지 않고 미국 등으로 단정하지 않습니다. 기존 개발자 소개 외부 링크를 누르면 해당 서비스로 이동합니다.

7. 자동 저장·조회수와 추적 도구

앱 자체의 쿠키, SessionStorage, IndexedDB, 광고·맞춤형 분석 SDK, AI 전송 코드는 확인되지 않았습니다. 앞서 설명한 기능성 LocalStorage와 도안별 누적 조회수를 사용합니다. 갤러리 검색어는 브라우저 메모리에서 목록을 거르는 데 쓰고 검색어를 서버에 보내는 코드는 없습니다. 외부 플랫폼의 자동 수집은 별도 확인 대상입니다. 필요 없는 쿠키 동의 배너나 로컬 편집 이용 동의는 추가하지 않았습니다.

2. Artwork and settings on your device

Pixels, pattern data, dimensions, color, brush, guides and the current screen are stored in this site’s browser LocalStorage (pixelworld:v1) to restore your work. Language (pixelworld:lang), the erase-tip flag (pixelworld:eraseHintShown) and gallery density (pixelworld:galleryDensity) are also stored. The code sets no automatic expiry. People using the same browser profile may access them. Autosaving does not upload your artwork to the gallery. Clear this site’s data in your browser to remove local storage. Clear all in the editor does not remove every setting or stored item.

3. Reference images, files, clipboard and share links

Reference images are read and displayed in the browser, without a code path that uploads or autosaves the image. Remove image or closing the page removes the displayed reference; the original file remains. Imported drawing or pattern JSON is read locally and may be saved as local working data. Downloaded JPG/JSON files and copied images are managed by your device and operating system. Share links contain compressed artwork after #art= in the URL. Compression is not encryption. Anyone with the link can restore the artwork; there is no access control, expiry or remote revocation. URL fragments are not part of normal HTTP requests, but sharing services, sync or history may retain the link. Opening it may also save the artwork in the recipient’s browser.

4. Information processed by the public gallery

Uploading sends the title, artist nickname, optional country code and name, pattern dimensions, shape, color legend and cells to Google Apps Script for storage in Google Sheets. The server also creates a post ID, timestamp and pattern view count. The gallery and public listing API allow anyone to read these data, without membership restrictions. Opening a gallery pattern sends its ID to Google to increment its view count. Country is a manually selected display field; no GPS collection feature exists. The gallery’s purpose is public pattern display and coloring. The legal basis for collecting and publicly disclosing any personal information, and any separate consent needed: [Operator confirmation required]. The current publication acknowledgment alone does not establish valid privacy consent. Keep real names, school, grade, class, student number, contact details and others’ personal information out of artwork and text.

5. Retention, deletion and disposal

Local working data have no automatic expiry and may remain until overwritten or this site’s data are cleared. The server gallery currently has no scheduled expiry or retention-based disposal code. The appropriate gallery retention period, deletion criteria and disposal process: [Operator confirmation required]. Users cannot edit or delete server posts themselves; only administrators can update or delete the corresponding row. Google Sheets version history, trash, backups and final disposal periods: [Operator confirmation required]. Deleting a row does not establish immediate permanent removal of all copies. Files or links downloaded or forwarded by others may remain separately.

Each destination may receive the IP address and HTTP request headers. No separate application access-log storage code was found; this does not mean platforms keep no logs. 7. Browser storage, view counts and tracking

No application cookie, SessionStorage, IndexedDB, advertising or personalized analytics SDK, or AI transmission code was found. The app uses the functional LocalStorage entries and cumulative pattern view counts described above. Gallery search terms filter the list in browser memory, with no code that sends the search term to the server. Automatic collection by external platforms requires separate verification. No unnecessary cookie banner or consent gate for local drawing has been added.

8. Children, guardians and school use

Children should use an invented nickname and avoid publishing their own or friends’ personal information. Guardians and teachers should explain the difference between local drawing and publishing for everyone to see. A nickname is not automatically non-personal information. Where consent is required for processing a child’s personal information under age 14, lawful guardian consent and verification are needed. The app currently has no verification process. The basis for public uploading and child-protection process: [Operator confirmation required]. Teacher permission is not assumed to replace guardian consent. Schools must check applicable education-authority requirements and external-service procedures.
